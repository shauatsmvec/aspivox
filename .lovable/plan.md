

# Aspivox EduTech Website

## Overview
Build a complete, modern, single-page EduTech website for Aspivox with smooth scrolling, animations, and a vibrant purple-blue gradient brand identity.

## Brand Setup
- Custom color palette: purple-blue gradient (#6C3EF4 → #3B82F6), orange accent (#F97316), dark navy (#0F172A)
- Inter/Poppins font via Google Fonts
- Custom favicon: gradient "A" letter SVG as data URI
- Tab title: "Aspivox | Start Today, State Tomorrow"
- Remove all Lovable branding

## Pages & Components

### 1. Navbar
- Sticky glassmorphism navbar with logo, nav links (Home, Courses, About, Team, Internship, Contact), and gradient "Enroll Now" CTA
- Mobile hamburger menu

### 2. Hero Section
- Dark navy background with animated gradient blob/mesh
- Bold heading, subheading, two CTA buttons, 3 trust badges, floating course card mockup

### 3. About Section ("Why Aspivox?")
- Split layout: company description + 4 feature icon cards (Live Sessions, Project-Based, Internships, Affordable)

### 4. Courses Section
- Grid of 9 course cards (Python, Java, C/C#, React, MERN, Data Science, IoT, GenAI, PHP) with icons, descriptions, gradient top border, hover lift

### 5. Internship Section
- Gradient background, timeline/cards for 5 duration options (15-90 days), highlights, CTA button

### 6. Achievements Section
- Dark navy background, 4 animated counter stats (70+ students, 9 courses, 5 internship options, 1 year)

### 7. How It Works
- 4-step horizontal flow with icons and connecting elements

### 8. Team Section
- 8 team member cards with gradient initial avatars, hover scale + glow effect

### 9. Vision & Mission
- Two-column split card layout with gradient backgrounds

### 10. Contact Section
- Company info + contact form with mailto fallback, social links

### 11. Footer
- Dark navy, logo + tagline, quick links, social links, no Lovable branding

## Animations & UX
- Scroll-triggered fade-in animations using framer-motion
- Smooth scroll navigation
- Animated counters in achievements section
- Hover effects on cards, buttons, and team members
- Fully responsive mobile-first design
